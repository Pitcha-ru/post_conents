# post_conents

Файлы для автопубликации выпусков «За 30 секунд». Репозиторий публичный: Buffer скачивает отсюда ролики по прямой ссылке `raw.githubusercontent.com`.

Файлы сюда кладёт сервис из приватного репозитория 30sec-celebrities, вручную в нём ничего менять не нужно.

- `video/ru/`, `video/en/` — ролики (в имени хеш содержимого)
- `dashboard/` — страница статистики и превью выпусков (открывается через GitHub Pages)
